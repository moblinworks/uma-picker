# Umamusume picker

Cloned from [favorite-picker](https://github.com/antialiasis/favorite-picker) and modified for Umamusume content.

This is a small webpage for sorting Umamusume by how much you like them, or by whatever criteria you want. You will be shown up to 20 Umamusume at once. Pick one or a few that you like above the others. After enough choices are made, your favorite will be displayed. After some more choices, your second favorite, etc. Stop at any time.

See the [original](https://github.com/antialiasis/favorite-picker) for more info.
